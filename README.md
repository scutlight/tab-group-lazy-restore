# 标签组懒恢复

![Chrome Web Store 宣传图](store-assets/promo-marquee-1400x560.png)

标签组懒恢复是一个 Manifest V3 Chrome 扩展。Chrome 恢复上次窗口后，它会保留每个窗口的当前标签页，收起其他标签页组，并使用 Chrome 原生标签卸载能力释放后台页面。

当前版本：`4.3.0`

## 主要能力

- 每个恢复窗口只保留当前标签页加载。
- 当前标签页所在分组保持展开，其他分组自动收起。
- 后台标签保留原网址、顺序、固定状态和分组归属。
- 点击已卸载标签时，由 Chrome 正常加载原网页。
- 支持未分组标签、固定标签和有声音标签的保护设置。
- 安装、更新或重新加载扩展时，不会自动整理标签页。

## 安全边界

扩展不会：

- 创建、删除、移动、分组或解组标签页；
- 用占位页替换真实网址；
- 按标签标题、分组名称或个人网址执行定制恢复；
- 将标签网址或浏览状态发送给开发者或第三方；
- 使用远程代码、广告 SDK 或分析 SDK。

Chrome 启动后、扩展开始运行前，少量后台页面仍可能短暂发出网络请求。扩展不会以修改或破坏标签数据的方式追求绝对零请求。

## 从源码安装

1. 下载或克隆本仓库。
2. 打开 `chrome://extensions/`。
3. 开启右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择仓库中的 `extension` 目录。

重新加载扩展不会触发自动整理。手动整理只能通过扩展面板中的按钮执行。

## 设置

- Chrome 启动时自动整理
- 收起其他标签组
- 卸载后台标签页
- 包括未分组标签页
- 保护固定标签页
- 保护正在播放声音的页面
- 立即整理当前窗口

## 权限

- `storage`：保存用户设置、执行结果和启动期间的去重状态。
- `alarms`：在 Chrome 恢复窗口期间执行有限次数的延迟检查。
- `tabs`：识别当前标签页、读取安全处理所需状态并调用原生卸载能力。
- `tabGroups`：读取分组归属，并收起或展开标签页组。

## 项目结构

```text
extension/       Chrome 扩展运行文件，可直接加载
tests/           Node.js 自动化测试和静态安全检查
docs/            GitHub Pages 隐私政策
store-assets/    Chrome Web Store 截图、图标和上架文案
.github/         GitHub Actions 自动测试
```

## 开发与测试

需要 Node.js 20 或更高版本，不需要安装第三方依赖。

```bash
npm run check
npm test
```

自动测试覆盖设置策略、启动恢复、当前标签恢复、安装/更新安全性、重复启动和标签切换竞态。静态检查禁止标签创建、删除、移动、分组、解组、网址写入以及个人化恢复规则。

## 隐私政策

隐私政策源文件位于 [PRIVACY.md](PRIVACY.md)，GitHub Pages 页面位于 [docs/index.html](docs/index.html)。创建仓库后需要替换其中的发布者名称和联系邮箱，再开启 GitHub Pages。

## 发布

Chrome Web Store 上传包应从 `extension` 目录内容生成，确保 ZIP 解压后 `manifest.json` 位于根目录。不要把仓库根目录整体作为扩展上传。

商店描述、权限说明和审核步骤位于 [store-assets/store-listing.zh-CN.md](store-assets/store-listing.zh-CN.md)。
