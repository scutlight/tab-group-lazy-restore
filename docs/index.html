标签组懒恢复隐私政策

生效日期：2026 年 8 月 18 日
发布者：Jevon Chen
联系邮箱：oicqchen@gmail.com

1. 适用范围

本隐私政策适用于 Chrome 扩展“标签组懒恢复”。本扩展的单一用途是：在 Chrome 恢复上次窗口后，保留每个窗口的当前标签页，收起其他标签页组，并安全卸载后台标签页。

2. 扩展处理的信息

为实现上述功能，扩展会在用户设备上的 Chrome 浏览器内处理：

  • 标签页和窗口状态，例如标签页 ID、窗口 ID、排列位置、是否为当前标签、是否固定、是否有声音、加载状态和卸载状态。
  • 标签页分组状态，例如分组 ID、成员关系和收起状态。
  • 标签页网址或待提交网址。扩展仅在本地短暂使用这些信息，以判断页面是否适合安全卸载、确认恢复结构是否稳定，以及识别旧版本可能遗留的扩展占位页。
  • 用户设置和最近一次执行结果。

3. 信息的存储和保留

  • 用户设置保存在 Chrome 提供的扩展同步存储中，直至用户更改设置、清除扩展数据或卸载扩展。
  • 用于识别当前标签页的结构标记保存在 Chrome 的本地扩展存储中，并会随使用情况更新。
  • 启动期间的临时执行状态保存在 Chrome 的会话存储中，通常在浏览器会话结束后清除。
  • 扩展不会建立远程数据库，也不会把标签页网址上传给发布者。

4. 信息的共享和用途限制

本扩展不把用户信息发送给发布者或第三方服务器，不出售、出租或转移用户信息，不用于广告、分析、画像或信用评估，也不包含第三方分析 SDK、广告 SDK 或远程代码。

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

对从 Google API 获得的信息的使用将遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求。

5. 权限用途

  • storage：保存设置、执行结果以及用于安全去重的本地或会话状态。
  • alarms：在 Chrome 启动后的短时间内安排有限次数的稳定性检查。
  • tabs：识别当前标签页、读取安全处理所需的标签状态，并调用 Chrome 原生卸载能力。
  • tabGroups：读取分组归属并收起或展开标签页组。

6. 用户控制

用户可以在扩展面板中关闭自动整理、后台卸载或分组收起，也可以选择保护固定标签页或有声音的标签页。用户可以通过 Chrome 的扩展管理页面清除扩展数据或卸载扩展，从而停止所有处理并删除 Chrome 保存的扩展数据。

7. 儿童隐私

本扩展不以儿童为目标，也不会有意收集儿童个人信息。

8. 政策变更

如本隐私政策发生实质性变更，发布者将在更新后的政策中修改生效日期，并按照 Chrome Web Store 的要求提供通知。
