# Chrome 应用商店资料

## 基本信息

- 名称：标签组懒恢复
- 版本：4.3.0
- 类别：生产力工具
- 语言：简体中文
- 建议首发可见性：不公开（Unlisted），验收稳定后再改为公开

### 简短说明

Chrome 恢复窗口时，只加载每个窗口的当前标签页，并自动收起其他标签页组。

## 详细说明

标签组懒恢复为经常使用 Chrome 标签页分组的用户，提供更安静、更节省资源的窗口恢复体验。

当 Chrome 使用“继续浏览上次打开的网页”恢复窗口时，扩展会识别每个窗口的当前标签页，保留它继续加载，并在确认窗口结构稳定后卸载其他后台标签页。后台标签仍保留原网址、顺序、固定状态和分组归属，点击时由 Chrome 正常重新加载。

主要能力：

- 每个恢复窗口只保留当前标签页加载
- 当前标签所在分组保持展开，其他分组自动收起
- 当前标签未分组时，其他分组仍会自动收起
- 后台标签使用 Chrome 原生卸载能力，不替换网址、不创建占位页
- 支持手动整理当前窗口
- 可选择是否保护固定标签页、有声音的标签页和未分组标签页
- 安装、更新或重新加载扩展时不会自动整理窗口

扩展不会创建、删除、移动、分组或解组标签页，也不会把浏览数据发送到外部服务器。

使用限制：

- Chrome 启动后、扩展接管前，少量后台网页可能已经短暂发出网络请求。
- 扩展不恢复网页内未提交的表单、滚动位置或其他运行时内存。
- Chrome 内部页面等不允许卸载的页面会被安全跳过。

## 单一用途说明

在 Chrome 恢复上次窗口后，保留每个窗口的当前标签页，收起其他标签页组，并安全卸载后台标签页，从而降低启动时的标签加载和资源占用。

## 权限说明

### storage

保存用户设置、上一次执行结果和启动期间用于防止重复处理的临时状态。数据只保存在 Chrome 提供的扩展存储中。

### alarms

在 Chrome 启动恢复窗口的短时间内安排有限次数的延迟检查，以覆盖较晚恢复的窗口、标签页和标签页组。

### tabs

识别每个窗口的当前标签页，读取标签页是否固定、有声音、正在加载或已卸载等状态，并调用 Chrome 原生标签页卸载能力。为判断标签页是否可以安全处理，扩展还会在本地短暂读取标签页的网址或待提交网址；这些信息不会发送到外部。

### tabGroups

读取标签页的分组归属，并收起其他分组或展开当前标签页所在分组。

## 审核人员测试说明

1. 在 Chrome 设置中选择“启动时 > 继续浏览上次打开的网页”。
2. 建立至少两个窗口，并在每个窗口建立多个标签页组和未分组标签页。
3. 在每个窗口选择一个当前标签页，然后正常退出 Chrome。
4. 重新打开 Chrome，等待最多约 30 秒，让窗口恢复和稳定检查完成。
5. 确认每个窗口的当前标签页保持加载；其他合格后台标签显示为已卸载。
6. 确认当前标签页所在分组展开，其他分组收起；网址、顺序、固定状态和分组成员关系没有改变。
7. 点击任一已卸载标签，确认 Chrome 正常加载其原网址。
8. 点击扩展图标，可查看设置、最近一次执行结果，并手动整理当前窗口。
